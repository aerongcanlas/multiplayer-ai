# Codex in the desktop app

The lead/specialist run that used a Codex App Server signed into ChatGPT has been replaced by chat tabs. Codex now runs in a tab like any other harness, with its native plan mode, the host's own Codex configuration, and per-tab approvals.

See [desktop-harnesses.md](desktop-harnesses.md) for managed programs, custom executables, sign-in, access modes, and troubleshooting.
